# API surface for stubgen.py — every METHOD/FIELD resolves against yarn-1.21.1.tiny.
# Format: CLASS|INTERFACE|HOLDER <binary> [ABSTRACT] [EXTENDS <bin>] [IMPLEMENTS a,b]
#   CTOR <desc>            (hand-written, trusted; validated by CI loom build)
#   METHOD <name> [STATIC] [ARGS <desc-substring>] [THROWS a,b]
#   FIELD <name> [STATIC]
#   RAW <full member source line>
# Rules: no getUuid/getId/getName/getDisplayName/getOwner/getTarget (avoidance);
# isPlayer -> instanceof; getBlockPos -> ofFloored(getX/Y/Z); getCustomName dropped.
# World/ServerWorld/ClientWorld are ABSTRACT in stubs (never extended by mod code,
# so interface links emit correct invokeinterface owners). Entity has NO interface
# links (mod entities extend it, so it must stay concrete with Entity-owned members).
